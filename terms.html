Términos de Uso

Última actualización: junio de 2025  ·  Aplicación web Finova
Al usar Finova aceptas estos términos. Si no estás de acuerdo, por favor no uses el servicio.

1. Descripción del servicio

Finova es una aplicación web gratuita de gestión de finanzas personales que permite registrar transacciones, hacer seguimiento de inversiones, calcular la fiscalidad IRPF, definir objetivos financieros y consultar un asesor con inteligencia artificial.

El servicio se ofrece «tal cual» (as is), de forma gratuita y sin garantías de disponibilidad permanente.

2. Registro y cuenta de usuario

  • Para usar todas las funciones debes crear una cuenta con un correo electrónico válido o iniciar sesión con Google.
  • Eres responsable de mantener la confidencialidad de tus credenciales de acceso.
  • Solo está permitida una cuenta por persona. Está prohibido crear cuentas automatizadas o con datos falsos.
  • Debes ser mayor de 16 años para usar el servicio.

3. Uso aceptable

Te comprometes a no usar Finova para:

  • Sobrecargar, atacar o interferir en el funcionamiento del servicio.
  • Distribuir malware, spam o contenido dañino a través del servicio.
  • Realizar ingeniería inversa o extraer el código fuente con fines comerciales sin autorización.

4. No constituye asesoramiento financiero

La información, cálculos y sugerencias que muestra la app —incluyendo las respuestas del asesor con IA— no constituyen asesoramiento financiero, fiscal, legal ni de inversión. Consulta siempre a un profesional cualificado antes de tomar decisiones financieras.

Los cálculos de IRPF, plusvalías y proyecciones son aproximaciones basadas en los datos que introduces. Finova no se responsabiliza de errores derivados de datos incorrectos o de cambios normativos.
